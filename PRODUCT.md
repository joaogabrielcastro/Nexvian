## 2.1. Público-alvo

Operadores de iGaming que precisam receber pagamentos em diferentes países e utilizar diversos provedores.

A Nexvian será uma solução B2B. O usuário final do cassino ou plataforma de apostas não será nosso cliente direto.

## 2.2. Produtos da plataforma

### Nexvian Payments

Motor principal de processamento e orquestração.

### Nexvian Console

Painel administrativo interno para gestão da infraestrutura.

### Nexvian Operator Dashboard

Painel destinado aos operadores clientes.

### Nexvian API

Interface de integração entre operadores e plataforma.

### Nexvian SDK

Biblioteca para facilitar integrações com a API.

## 2.3. Funcionalidades

| Módulo | Responsabilidade |

| Ledger | Registro financeiro |

## 2.4. Modelo comercial inicial

- SaaS: mensalidade pela utilização da plataforma.
- Transaction Fee: taxa por transação processada.
- White-label: plataforma personalizada para clientes.
- Enterprise: contratos e integrações específicas.

Os valores comerciais serão definidos após validação do mercado, custos de provedores e estrutura regulatória.
